📜 BEGINNER COMMANDS CHEAT SHEET

Here are the raw underlying cURL and Terminal commands executed by this app:

1. Request API Key (cURL) 
curl -X POST "https://api.ditto.site/v1/signup/request" \
  -H "Content-Type: application/json" \
  -d '{"email":"your-email@domain.com"}'
2. Submit Clone Job (cURL) 
curl -X POST "https://api.ditto.site/v1/clones" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "url": "https://example.com",
    "options": { "mode": "multi", "framework": "next", "styling": "tailwind" }
  }'
3. Check Clone Job Status (cURL) 
curl -H "Authorization: Bearer YOUR_API_KEY" \
  "https://api.ditto.site/v1/clones/YOUR_JOB_ID"
4. Download & Extract Bundle (Bash) 
curl -L -H "Authorization: Bearer YOUR_API_KEY" \
  "https://api.ditto.site/v1/clones/YOUR_JOB_ID/bundle?format=tgz" \
  | tar -xzf - -C ./cloned-site
5. Run Cloned Site Locally (Terminal) 
cd cloned-site
npm install
npm run dev
